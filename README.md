# BiTabakda prototipi

Bu GitHub Pages demosu örnek içeriklerle hazırlanmış mobil uyumlu web arayüzüdür. Ürün veya gerçek sipariş hizmeti değildir.

- Arama ve kategori filtreleri
- Beğeni, yorum, takip ve örnek metin paylaşımı
- Demo sipariş ve mesaj geri bildirimi

Gerçek kullanıcı hesabı, veri saklama, sipariş, ödeme, kurye ya da kimlik doğrulama bağlantısı içermez. Demo profilleri, yemek görselleri ve etkileşimler temsili veridir.

Onaylı logo SVG'si bu yayın deposuna dağıtım amacıyla alınmıştır.
